## 公开源码包

执行 `pnpm release:prepare` 生成独立源码目录和 `.tar.gz` 文件。包内含许可证、源码、完整示例、锁文件、公开文档、验证脚本和 GitHub 配置；生成文件在安装后通过 `pnpm build` 重建。

CI 配置 Windows / Ubuntu 的安装和发布检查。Pages 为手动工作流，部署到仓库子目录时使用实际 Pages 基础路径。远端执行状态见仓库工作流记录。

## 宣传页设计

主参考为 Notion 的暖色留白、克制边框与清楚的文字层级；Framer 的产品演示节奏作为辅助参考。实际实现沿用 own-ui 的森林绿、暖白、Manrope / Noto Sans SC 字体和共享组件，未使用参考品牌的专有字体或素材。

## 使用范围

React + Vite、Next.js 使用相同源文件。Vue、Svelte、原生移动端需要各自实现。组件不承担路由、请求、鉴权与持久化。

未在真实桌面宿主、低性能手机、Firefox 或 Safari 验收。真实 IME 组合输入与头像图片加载失败回退未做浏览器检查；本次只检查了相关代码或边界。视觉仍待用户审查。
